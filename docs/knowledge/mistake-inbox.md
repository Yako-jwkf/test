# ミス置き場(未処理のミス)

要約: 起きたミスを、見つけたその場で1行ずつ置く。ここから `/reflect` でルール・スキル・フックに変える。処理したら状態を書き換え、採用したものだけ [mistakes.md](mistakes.md) の台帳に載せる。

## 書き方
- 1件1行。「何が起きたか」は指摘の原文か失敗の出力をそのまま書く。原因の推測はここに書かず、[原因の表](mistake-causes.md)の節に書く(2026-10-06 から。それより前の行は混ざったまま)。
- 見つけ方: ユーザー指摘 / 自分 / テスト / 安全チェック / フック
- 対策: 対策を置いたかだけを書く。未処理 / ルール化 / スキル化 / 仕組み化 / 見送り(理由)。処理先を添える。直ったかはここに書かない(2026-10-06 まで「状態」と呼んでいた列)。
- 原因: [原因の表](mistake-causes.md)の番号(複数なら「、」で区切る)。まだ決めていなければ「未分類」、精査してミスではなかったら「対象外」。
- 直ったか(解消したか)は `python3 scripts/mistake_check.py` で判定する。原因ごとに、対策の後の再発と擬似解消関数の結果を出す。
- 原因が同じ行が2件以上たまったら、ルール(お願い)より仕組み(スキル・フック)を優先して考える。
