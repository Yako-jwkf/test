# ナレッジベース

ここに調べたこと・決めたこと・手順を Markdown で残します。

## 書き方
- 1トピック1ファイル。ファイル名は `topic-name.md`(英小文字とハイフン)。
- 先頭に1行で要約を書く。
- 根拠(URL、日付、コードの場所)を添える。
