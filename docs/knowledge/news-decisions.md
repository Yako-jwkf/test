# news の食い違いへの判断

要約: news(https://github.com/Yako-jwkf/news)の号が「1. 食い違い」に出したものを、このリポジトリに取り込んだか・見送ったかの記録。決めたことなので、news ではなくここに置く。news の定期実行はこのファイルを読み、「見送り」のものを次の号に出し直さない(news の `PROMPT.md` の 3-7)。

## 書き方
- 1件1行。会話の中で決めたときに足す(例: 「10-13 の号の食い違い1を直して」→ 直したら「取り込んだ」)。
- 判断は「取り込んだ」「見送り」のどちらか。見送りには理由を書く。
- 取り込んだときは、直したファイルを書く。
