# ミスから作ったルールの台帳

要約: `CLAUDE.md` の「してはいけないこと」の各行について、いつ・何をきっかけに作ったかを残す。出どころがわかれば、効いていない行をあとで消せる。

## 運用
- ルールを足すときは、ここにも1行足す(`/reflect` の手順)。
- `CLAUDE.md` の「してはいけないこと」は10行まで。超えたら統合するか、特定の作業でしか要らないものをスキルへ移す。
- 根拠: 説明書を増やすと成功率が下がりコストが増える(AGENTbench 2602.11988、Signal or Noise? 2608.23067)。詳細は [agent-config-research-2026.md](agent-config-research-2026.md)。
