# エージェント設定に関する研究(2026年2月〜9月)

要約: 「たくさん書き足す」より「少なく、〜するな型で、必要なときだけ」。守らせたい線は仕組み(sandbox)で守り、他人の設定は中身を確認してから入れる。

調査日: 2026-09-30

## 注意点
- arXiv の論文の多くは、他の研究者による審査(査読)の前の段階。
- この環境からは arXiv の本文を開けず、要旨と解説記事で確認した。
- 日付は論文番号から読める投稿月(`2609` = 2026年9月)。日まで書いたものは確認できた日付。
- 実験の多くは1つ前の世代(Claude 4.6 など)のモデルで行われている。
- 研究結果は参考にするが、それが最善とは限らない。

## このリポジトリへの反映
- CLAUDE.md は短くし、ルールは「〜するな」の形で書く。過去のミスから作る(2026-09-30 反映)。
- push は `permissions.ask` で、実行前に必ず確認を求める(2026-09-30 反映)。
- スキルやフックは、困りごとが出てから1つずつ足す。他人が作ったものは中身を読んでから入れる。
